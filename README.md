# Software Engineering 2
This repository has been created for the "Software Engineering 2" course at Politecnico di Milano.

Its primary focus is on two key aspects:
1. The preparation of a Requirement Analysis and Specification Document (RASD) for a given problem.
2. The development of a Design Document (DD) for the system mentioned in the first point.
